# V4 七屏逐项拆解与实施清单

目标：按用户确认的两张原型图实现原生 iOS 图片工作台，真实编辑、保存、批量和 PCM/Chat 共用。2026-09-27 已核对并拆解确认稿；实际验收结果见 completion manifest。

## 视觉基准

原图：[编辑三屏](approved-editing.png)、[保存与批量四屏](approved-export-batch.png)。
画板外围编号、竖排宣传文案、叶子装饰不属于 App 屏幕。状态栏/Home Indicator 使用系统显示，不烘焙到资源。屏幕内实拍图是编辑内容；生产展示用户图片，验收使用固定样片。两张AI设计图的校园照片并不完全一致，视觉回归统一固定样片，不能用更换示例照片冒充像素编辑效果。

复用 AppTheme：背景F7F5EF、卡片FFFFFF、选中mint DDECE2、sky DFEBED、lilac E7E6F1、ink1F2D2E、secondary667373、交互3F7278、accent6673A6；保存CTA复用actionGradient。布局间距以现有Spacing为准；图标24pt级，按钮命中区域至少44pt；照片使用aspectFit及准确内容坐标，避免为截图相似而裁掉用户照片。

## 组件与状态

1. 编辑导航：返回/标题/保存胶囊，顶部安全区；在工具内变为取消/工具名/完成。busy时阻止重复保存，但允许有定义的取消。
2. 画布：照片、棋盘透明底、文本/图片选框和角点；手势协调为单指对象/画笔、双指画布缩放；内容坐标映射与导出统一。
3. 悬浮画布操作：撤销、重做、对比、图层；深色半透明圆形背景保证照片上可读。
4. 工具托盘：2×4浅色工具格，图标+中文标签，主屏始终显示主工具；工具展开后原位置成为底部参数面板。
5. 参数面板：标题/分段选择/选项条/滑杆/数值步进，文字、调色、修复提供取消/完成；取消恢复进入工具时的参数。
6. 文本面板：输入、多行；字体/样式/颜色/排版；字体卡、字号、色板+自选、对齐。使用系统黑体、已打包的站酷小薇与马善政手写体；样式支持描边和阴影。
7. 图层面板：缩略图/名称/显隐/锁定/排序；新增/复制/删除；透明度、混合模式。背景图允许锁定但不能误删成空输出。
8. 滤镜条：实时基于当前图片生成缩略图，原图/晴日/薄荷/胶片；预设版本固定；强度0显示原图。
9. 调色面板：曝光、对比、饱和、色温、阴影等可编辑值；归零、取消、完成；降低预览分辨率不降低保存分辨率。
10. 修复面板：掩膜、放大镜、涂抹/擦除、画笔大小、撤销、预览/应用；显示真实结果。算法不可用必须报错，禁止用模糊覆盖伪装修复。
11. 保存面板：缩略图、PNG/JPG、JPEG画质、尺寸比例/宽高锁、文件名、编码后真实字节、保留原图、草稿开关、移除位置开关、保存副本。PNG不显示JPEG有损画质。
12. 批量面板：多选6图网格示例、样片徽标、添加/移除、同步设置复选框、保存N张。处理状态逐图显示，取消未开始项，失败单独重试。
13. 完成状态：保存页/批量页收到真实收据后显示成功；保留导出分享、相册按钮和返回编辑。用户取消分享不影响已保存结果。
14. 错误/空态：照片权限/无照片、读取失败、12MiB/24MP限制、上传失败、账号切换、无前景主体、选中背景、不可用字体、存储失败、部分批次失败。

## 配图/资源

- 用户选图是主画布资源：不内置固定校园人物到真实编辑流程。
- 原型同款阳光校园样片可作为Demo/UI验收fixture，独立标记、不上传或伪装用户素材。
- 滤镜小图从当前图片计算，图层缩略图从各真实对象计算，不能用静态预制小图。
- 字体样例由实际字体渲染；文字描边/阴影来自参数，导出同一实现。
- 透明棋盘、选框、角点、滑杆、颜色点均为原生绘制；无需新增位图资源。
- 局部放大镜来自当前图片实际像素区域；批量缩略图来自所选图片。

## 接口命中与验收

从现有WorkflowCreateSheet“图片”入口进入共享ImageWorkbench；Chat ImageCard仍调用相同编辑器。操作参数与ImageEditSupport/NativeImageProcessAction共用，APIClient通过现有认证访问保存；media.process扩展注册，不单建工具注册中心。
后端要校验输入/操作边界、source owner/hash、输出格式尺寸、参数版本、幂等和收据；不把客户端报告成功当服务端重算证明。单图保存和批量每图回执需要完整来源记录。

验收顺序：参数与越界测试→真实像素输出→原生编译与模拟器七屏截图→固定样片视觉对照→手动端到端→Chat媒体调用/设备回执→批量部分失败与账号隔离。未通过前不声明1:1或完整功能可用。

## 实现复用

- `ImageWorkbench`：Workflow「处理图像」与已有 Chat 图片卡共用。
- `ImageStudioRecipe`：同一份版本化参数用于手动预览、保存和 Chat 的 `media.process`。修复选区与主体点位使用构图前原图坐标；图层保持最终画布相对位置。高级配方使用 `image_studio_v1` 设备动作，避免旧客户端忽略新参数后误报成功。
- Mantis 3.1.0：裁剪、旋转、翻转，保存归一化四角坐标。
- Core Image / UIKit / ImageIO：滤镜、调色、文字图层、透明 PNG / 白底 JPEG、尺寸与编码质量。
- iOS Vision：前景实例提取。
- OpenCV 4.13.0：Telea 污点修复，只按明确画笔选区处理。SPM 包锁定版本和 SHA256；Apache 2.0 许可证随 App 打包。
- `media.save_edit`：复用 generated artifacts 私有存储，验证 owner、原图哈希、图层素材、输出尺寸与格式，原子保存与幂等重试。
- 批量通过同一保存入口逐图执行，不引入第二个任务引擎；20张、总输入60MB，修复和抠图只作用于样张。
- 字体使用系统黑体及随 App 打包的站酷小薇、马善政手写体（SIL OFL 1.1），预览与导出共用同一字体；许可证与 SHA256 见 `ios/AIPlatformApp/Fonts/README.md`。

验收结果以 completion manifest 为准；设计图不代表实际编译和运行结果。
