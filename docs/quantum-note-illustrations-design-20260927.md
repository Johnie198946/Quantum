# 笔记 UI 与智能配图实现说明

用户已通过“综合一下，帮我完成我所有需求的开发”授权实现此前讨论的边界扩展。代码已实现；验证结果与实际交付状态见 `ops/change-manifests/quantum-note-illustrations-20260927-completion.md`。未部署。

## 使用方式

- 普通笔记：进入编辑，底部「格式」插入提示块、卡片、代码块与图表；「图片」选择相册照片。阅读时使用既有高亮／批注菜单。
- 旅行笔记：笔记首页「更多 → 新建旅行笔记」，或普通笔记「更多 → 使用旅行版式」。聊天／旅行工作流的保存入口仍保留。编辑目的地、日期和游记时保持结构化行程与自定义字段。
- 自动配图：编辑后点击「完成」、保存聊天草稿或旅行成果时发起；输入时的自动落盘不触发生图。「更多 → 保存时自动配图」可关闭。
- 手动配图：在编辑器段落定位光标 →「AI 配图」→ 输入想画的内容 → 生成 → 预览并「插入笔记」。旅行概览／地点使用「为这里配图」，无需编辑 JSON。
- 生成可以关闭面板继续写作；查看配图可恢复面板，支持停止、失败重试、重新生成。自动插入后可撤销本批图片。

## 设计与数据规则

沿用暖白、薄荷绿、雾蓝和浅紫；普通笔记使用清晰圆润的标题与轻量提示卡，旅行保持衬线大封面、分区行程和地图。真实笔记不再回退京都示例、虚构天气或预约状态；无照片时使用中性地图封面。

自动规划每次 0–3 张，复用现有 HTML 段落选位评分；排除短段落、代码、列表、表格和已配图位置。这是确定性启发式，不额外调用文字模型。图片提示包含全文、标题、目标段落、前后文及用户要求。统一清新插画风格，真实地点明确采用艺术插画而非冒充实拍。

普通笔记用相对 Markdown 图片引用；旅行 JSON 增加可选 `illustrations` 数组（anchor/path/alt），保留原字段。生成成功先缓存带 SHA256 的私有 JPEG，再插入。图片由带身份认证的接口获取；换设备读到引用后可重新下载生成图片。本次未扩展任意相册图片的跨设备二进制同步。

正文或尚未落盘的草稿变化时不覆盖，保留候选并允许重新选位。重复保存相同版本不重复生成；重试复用成功图片；账号切换、取消或笔记已不存在时不应用旧结果。任务和计划持久化，App 重开可恢复查询和已完成候选。

## 复用与必要新增

复用 `KnowledgeNoteStore` 账户 Vault、`APIClient` 认证下载／SHA 校验与笔记同步队列、`knowledge_sync` 用户命名空间、Hermes 持久任务／worker／租户归属校验、现有 image provider。没有添加第三方依赖或平行运行时，也没有开放通用图片工具权限。

必要新增：笔记专用输入／输出契约、选位与图片执行逻辑、私有资产路由，以及 iOS 的任务记录和配图面板。后台任务标为 `note_illustration`，不进入普通聊天列表。

公开路由（均需认证）：
- `POST /api/v1/me/knowledge-notes/illustrations/generate`
- `GET /api/v1/me/knowledge-notes/illustrations/{run_id}`
- `POST /api/v1/me/knowledge-notes/illustrations/{run_id}/cancel`
- `GET /api/v1/me/knowledge-notes/illustrations/{run_id}/assets/{index}`

内部 Bridge 使用 `/v1/note-illustrations`，沿用内部 token 与服务端派生 tenant/user；用户不能指定宿主路径或任意图片 URL。图片由已配置 provider 生成、解码检查、缩放并重新编码。

## 现有配置与边界

本机实际验证 provider `volcengine-seedream`，model `doubao-seedream-5-0-pro-260628`。真实生成测试已产出并人工检查清新校园插画；没有修改 Hermes 配置或输出密钥。插画规划参考现有 illustrate-articles 思路；未声称未启用的 baoyu 技能正在运行。

- 单篇请求上限 48,000 字符，超过时明确提示拆分；不截断全文。
- 停止可阻止排队后续工作和结果插入；已经发给外部 provider 的单次调用不保证撤销计费。
- 本地源码、模拟器、契约测试和本机真实 provider 分别验证；生产运行时配置及真实账号端到端仍需部署阶段验证。
- 生产生成图片目录应与既有持久任务数据库一起备份。当前未增加自动删除策略，避免已插入图片失效。
