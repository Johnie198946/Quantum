# 首次使用者观察验收

## 自动化前置

- 入口发现、欢迎态与键盘可达性：`/tmp/Quantumn-Remediation-Novice-All.xcresult`
- 结果：6 passed / 0 failed / 0 skipped
- 覆盖：阅读入口、聊天欢迎态、窄屏、键盘遮挡、按钮可点击、错误恢复文案。

## 被试条件

- 从未使用过 Quantumn。
- 不参与本项目开发与测试。
- 测试前不阅读操作说明。
- 观察者不得口头引导、指示点击位置或解释产品术语。

## 任务

> 创建一份 PPT，确认需求，检查并修改全稿，下载可编辑 PPTX。

## 通过标准

1. 被试能自行找到 PPT 创建入口。
2. 被试能判断需求确认页的下一步。
3. 默认主路径只暴露“需求确认 → 全稿预览 → 下载”。
4. 被试能在全稿预览中修改标题、列表、页面结构或素材。
5. 错误或冲突出现时，被试能根据页面文案选择重试、载入远端或保留本地。
6. 被试能完成下载，不需要观察者解释 Runtime、handler、node 或 gate。
7. 无阻断性误点；犹豫点、误点、退出点均有时间戳与页面截图。
